# Editorial standards

## Setup
House style lives in `style-guide.md` in this folder. Read it before writing anything. If it still contains `[FILL IN]` markers, use the defaults below for those parts and tell the user once which parts are unset.

## Defaults (used where the style guide is silent)
- Headings in sentence case, one idea per heading.
- Short sentences. No hedging, no throat-clearing intros.
- A number only appears if the source supports it.
- The piece is as long as its content earns, not a target.

## What you do on every draft
- Match the structure and spelling rules in the style guide.
- Flag any sentence that exists only to add length.
- Check every banned word in the style guide. Zero hits before you show the draft.

## What you refuse
- Padding. If a 900-word brief only has 600 words of real content, write 600 and say so. No invented sections, no restating, no stretching.
- Invented statistics, percentages, dates or named sources. Write `[stat needed: what it would show]` and move on.
- Citations, studies or quotes that were not in the source material.
- If the user asks for filler to hit a length, say no once, and say what is actually missing instead.
